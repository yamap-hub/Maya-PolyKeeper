PolyKeeper Lite (v0.0.1) - Maya 押し出しミス・トポロジー自動監視＆チェックツール（検出専用版）
================================================================================

【概要】
PolyKeeper Lite（ポリキーパー ライト）は、Mayaでのモデリング作業中に頻発する
「押し出しのキャンセル放置（厚みゼロの重複面）」や「ノンマニホールド（非多様体）」、
「五角形以上の多角形（Nゴン）」をバックグラウンドで監視・検出するための
Maya用アシスタントプラグイン（検出専用版）です。

初学者のセルフチェック漏れ防止から、提出前や次工程前のポリゴン検証まで、
クリーンなトポロジーの維持を自動でサポートします。


--------------------------------------------------------------------------------
■ 主な機能
--------------------------------------------------------------------------------
1. 押し出し放置のリアルタイム警告
   - `Ctrl + E` 実行後に移動やオフセットを行わず、選択解除や別ツール（W/E/Rキー）へ
     切り替えた瞬間、ビューポート上部に赤いバナーで即座に注意喚起します。
   - 「Esc ではなく Ctrl+Z で取り消す」習慣づけをサポートします。

2. 重複フェース・面積ゼロ面の検出と面ハイライト
   - 部分的な押し出し放置や、全面押し出しによる二重シェル・ラミナ面を検出し、
     該当するフェースをビューポート上でわかりやすく面ハイライト表示します。

3. ノンマニホールド（非多様体ジオメトリ）の検出
   - 1本のエッジに3枚以上の面が接するT字結合や、蝶ネクタイ状の頂点を検出します。

4. 多角形（五角形以上 / Nゴン）の検出
   - サブディビジョンやゲームエンジンで破綻の原因となる五角形以上の面を検出します。

5. シーン保存時（Ctrl + S）の自動全走査
   - ファイル保存時にバックグラウンドでシーン全体を高速スキャンします。
   - ミスを含んだままの保存や提出を防ぎます。

--------------------------------------------------------------------------------
■ インストール方法（ドラッグ＆ドロップ）
--------------------------------------------------------------------------------
複雑なコードのコピー＆ペーストやフォルダ配置は不要です。

1. Maya を起動します。
2. 解凍したフォルダ内にある `install_PolyKeeper_Lite.mel` を、
   Maya のビューポート（作業画面）内にそのまま「ドラッグ＆ドロップ」してください。
3. 自動的にスクリプトが配備され、現在開いているシェルフに「PKLite」ボタンが追加されます。
4. 「インストール完了」のダイアログが表示されればセットアップ完了です（即座に監視が開始されます）。


--------------------------------------------------------------------------------
■ 使い方
--------------------------------------------------------------------------------
【基本操作】
・シェルフの「PKLite」アイコンを【左クリック】
  → 現在のシーン全体をスキャンし、結果を表示します。
     問題がある場合はエラー箇所が面ハイライトされ、ダイアログに手動修正のヒントが表示されます。
     また、バックグラウンドでの自動監視（保存時チェック等）も同時に有効化されます。

【シェルフの右クリックメニュー】
・自動監視を再開 (Start Monitoring)
  → バックグラウンド監視を有効化します。
・自動監視を停止 (Stop Monitoring)
  → 一時的に保存時チェックや警告表示を停止したい場合に使用します。
・クレジット・バージョン情報 (About)
  → バージョン情報やサポートURLを確認できます。


--------------------------------------------------------------------------------
■ トラブルシューティング / アンインストール
--------------------------------------------------------------------------------
Q: Mayaを再起動したら監視が動いていない
A: シェルフの「PKLite」ボタンを1回クリックしてください。
   そのセッションでの監視が再び有効になります。

Q: アンインストールしたい
A: 1. シェルフ上の「PKLite」アイコンを右クリックして削除（Delete）してください。
   2. 以下のフォルダ内にある `poly_keeper_lite.py` を削除してください。
      Windows: C:\Users\<ユーザー名>\Documents\maya\<バージョン>\scripts\
      macOS  : /Users/<ユーザー名>/Library/Preferences/Autodesk/maya/<バージョン>/scripts/
