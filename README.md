================================================================================
PolyKeeper Lite (v0.1.0) - Maya 押し出しミス・トポロジー自動監視＆チェックツール（検出専用版）
================================================================================

【概要】
PolyKeeper Lite（ポリキーパー ライト）は、Mayaでのモデリング作業中に頻発する
「押し出しのキャンセル放置（厚みゼロの重複面）」や「ノンマニホールド（非多様体）」、
「孤立頂点（エッジ上の不要頂点）」、「五角形以上の多角形（Nゴン）」を
バックグラウンドで監視・検出するためのMaya用アシスタントプラグイン（検出専用版）です。

ミスが発生した瞬間のリアルタイム警告バナー通知、保存時の自動全走査、
エラー箇所の面ハイライト表示により、初学者のセルフチェック習慣づけから
提出前・次工程前の品質管理までを強力にサポートします。

■ 主な機能 (v0.1.0)
--------------------------------------------------------------------------------
1. 全エラーのリアルタイム警告バナー通知（文字幅・行数自動フィットUI）
   - 押し出し放置（Ctrl+E後に動かさず選択解除/ツール切替）の注意喚起
   - 重複フェース / 面積ゼロ面発生の即時警告
   - ノンマニホールド（T字結合・蝶ネクタイ頂点等）発生の即時警告
   - 孤立頂点（エッジ削除時の頂点消し残し等）発生の即時警告
   - 五角形以上の多角形（Nゴン）発生の即時警告

2. 重複フェース・面積ゼロ面の検出と面ハイライト
   - 部分押し出しによる潰れた側面フェースだけでなく、重なっている「天面」を
     特定して1箇所としてカウントし、面全体をオレンジ色でハイライト表示します。
   - 全面押し出しによって生じる「同座標の二重シェル」も確実に検出します。

3. ノンマニホールド（非多様体ジオメトリ）の検出
   - 1本のエッジに3枚以上の面が接するT字結合や、蝶ネクタイ状の頂点を検出します。

4. 孤立頂点（エッジ上の頂点含む）の検出
   - エッジを Delete / Backspace で消した際に残る「エッジ上の2価頂点」や、
     オープンボーダー上の直線孤立頂点、完全な浮き頂点を検出・ハイライトします。

5. 多角形（五角形以上 / Nゴン）の検出
   - サブディビジョンやゲームエンジンで破綻の原因となる五角形以上の面を検出します。

6. シーン保存時（Ctrl + S）の自動全走査
   - ファイル保存時にバックグラウンドでシーン全体を高速スキャンし、
     ミスを含んだままの保存・提出を未然に防止します。

■ インストール方法（ドラッグ＆ドロップ）
--------------------------------------------------------------------------------
複雑なコードのコピー＆ペーストやフォルダ設定は不要です。

1. Maya を起動します。
2. 解凍したフォルダ内にある `install_PolyKeeper_Lite.mel` を、
   Maya のビューポート（作業画面）内にそのままドラッグ＆ドロップしてください。
3. 自動的にスクリプトが配備され、現在開いているシェルフに「PKLite」ボタンが追加されます。
4. 「インストール完了」のダイアログが表示されればセットアップ完了です（即座に監視が開始されます）。

■ 使い方
--------------------------------------------------------------------------------
【基本操作】
・シェルフの「PKLite」アイコンを【左クリック】
  → シーン全体をスキャンし、結果を表示します。
     エラーがある場合は該当箇所がハイライト選択され、ダイアログに手動修正のヒントが表示されます。
     また、バックグラウンドでの自動監視（保存時チェックやリアルタイム警告）も同時に有効化されます。

【シェルフの右クリックメニュー】
・自動監視を再開 (Start Monitoring)
  → バックグラウンド監視を有効化します。
・自動監視を停止 (Stop Monitoring)
  → 一時的に保存時チェックや警告表示を停止したい場合に使用します。
・クレジット・バージョン情報 (About)
  → バージョン情報やサポートURLを確認できます。


--------------------------------------------------------------------------------
■ エラー検出時の手動修正ヒント
--------------------------------------------------------------------------------
・重複面 / 面積ゼロ面:
  直後なら Ctrl + Z で取り消すか、頂点を選択して「メッシュの編集 > 結合 (Merge)」。
・ノンマニホールド:
  不要な内部面・飛び出し面を削除するか、「メッシュ > クリーンアップ (Cleanup)」。
・孤立頂点（エッジ上の頂点含む）:
  ハイライトされた不要頂点を選択し、キーボードの Delete キーで削除。
・五角形以上（Nゴン）:
  「マルチカット」でエッジを引いて4角形以下に分割。


--------------------------------------------------------------------------------
■ トラブルシューティング / アンインストール
--------------------------------------------------------------------------------
Q: Mayaを再起動したら監視が動いていない
A: シェルフの「PKLite」ボタンを1回クリックしてください。
   そのセッションでの監視が再び有効になります。

Q: アンインストールしたい
A: 1. シェルフ上の「PKLite」アイコンを右クリックして「削除 (Delete)」してください。
   2. 以下のフォルダ内にある `poly_keeper_lite.py` を削除してください。
      Windows: C:\Users\<ユーザー名>\Documents\maya\<バージョン>\scripts\
      macOS  : /Users/<ユーザー名>/Library/Preferences/Autodesk/maya/<バージョン>/scripts/
