■ 概要
「PolyKeeper」は、Autodesk Mayaでのモデリング中にありがちな「押し出し（Ctrl+E）のキャンセルミスによる重複フェース」や「ノンマニホールド（非多様体）」、「五角形以上の多角形（Nゴン）」を自動で見つけて赤くハイライトしてくれる、Maya用検出・見守りスクリプトです。

モデルデータを勝手に書き換えることがない「検出・ハイライト専用設計」のため、初心者の方の学習用からプロの制作現場まで、安全にパイプラインへ導入いただけます。
---
■ 主な機能
1. 押し出し放置のリアルタイム警告
   「Ctrl + E」で押し出しを実行した直後、面を動かさずに選択解除や別ツール（W/E/R/Qキー）へ切り替えた瞬間に画面上部へ警告バナーを表示します（「EscではなくCtrl+Zで戻す」習慣をサポートします）。
2. シーン保存時（Ctrl + S）の自動スキャン
   ファイルを保存した瞬間にバックグラウンドでエラーチェックを実行。エラーに気づかず作業を進めてしまうトラブルを防止します。
3. シェルフ右クリックの個別フィルター選択
   「重複面のみ」「ノンマニホールドのみ」「五角形以上のみ」を右クリックからピンポイントで絞り込んで選択できます。
---
■ 導入方法（10秒で完了）
スクリプトエディタを開く必要はありません。
1. Mayaを起動します。
2. 追加したいシェルフタブ（[Custom]など）を開きます。
3. ZIP同梱の「install_PolyKeeper.mel」を、Mayaのビューポート（作業画面）にそのままドラッグ＆ドロップしてください。
4. シェルフに「PKeeper」ボタンが追加されれば設定完了です。
